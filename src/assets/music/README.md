# Musikstuecke

Jede Audiodatei in diesem Ordner (`.mp3`, `.ogg`, `.m4a`, `.wav`) taucht
automatisch als waehlbares Stueck im Spielmenue auf. Der Dateiname ohne
Endung ist der angezeigte Name; Unterstriche werden zu Leerzeichen.

    tavernen_abend.mp3   ->   "tavernen abend"

## Bevor du etwas hierher legst

Die Dateien werden mit der Seite veroeffentlicht - das ist Verbreitung, nicht
Privatgebrauch. Es geht also nur mit Musik, die das erlaubt:

- **CC0 / Public Domain** - keine Auflagen, der einfachste Fall.
- **CC-BY** - erlaubt, verlangt aber Namensnennung. Trag den Urheber dann in
  `THIRD_PARTY.md` ein, so wie es dort fuer die Kacheln steht.
- **Gekaufte Lizenz** - pruefe, ob sie Weitergabe im Web abdeckt.

Nicht geeignet: alles von YouTube, Spotify und aehnlichen Diensten, auch
wenn es sich herunterladen laesst.

Brauchbare Quellen mit klarer Lizenz sind OpenGameArt, Free Music Archive und
incompetech.com (Kevin MacLeod, CC-BY).

## Wenn der Ordner leer bleibt

Dann spielt das Spiel seine erzeugte Musik - eine langsame Melodie in
dorischem Modus ueber einem Bordunton. Sie braucht keine Datei und keine
Lizenz, klingt aber naturgemaess schlichter als eine Aufnahme.
